IgelkottFisheye Stabilizer

Remove the shake from a fisheye or 360° plate in Live FX: tracked keys in, a stabilizing curve out. Everything stays on this computer.

1The tracked point

Fisheye plate: set the clip's IgelkottFisheye node to Mode: Tracking view, aim it with Yaw at something far away on the horizon, then Framing → Stabilize → Track 1 Point → Apply to Framing, and export Framing Offset X and Offset Y from the Curve Editor.
360° plate (equirect): track with Stabilize the same way and export the keys it wrote — Pan 360 Yaw / Pitch / Roll in degrees, or Framing Offset X / Y in pixels.
Drop the export here (one file with all the curves, or one file per curve).

2Road and shake

The slow part of the movement is the road turning and stays in the picture. The fast part is the shake and becomes Stab Yaw.

A spike is the tracker slipping onto something in the foreground. Still see one? Drag across it in the lower chart.

3Save and import

  1. In Live FX, select a wall's IgelkottFisheye node and open the Curve Editor.
  2. Select Stab Yaw → Import → choose the saved file. Repeat for every wall.
  3. Stab Pitch: leave it at 0, or import Stab Pitch.csv the same way if you ticked “Stabilize pitch too”. Stab Roll stays at 0.
  4. If the picture shakes more, open Options, tick Invert direction (or Invert pitch) and import again.
  5. Set the clip's node back from Tracking view when you are done.
  6. 360° plate without IgelkottFisheye: import the curve onto the same parameter the keys came from (for example Pan 360 → Yaw), in place of the keys Stabilize wrote.
